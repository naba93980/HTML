# HTML - WebDev

A collection of HTML examples and practice code written while learning the fundamentals of web development.

## About

This collection contains HTML code which were created while following tutorials and experimenting with HTML elements, document structure, and the building blocks of web pages.

It serves as a personal archive of my early practice with HTML and a reference for revisiting the concepts I explored.

## Topics

- HTML document structure and boilerplate
- HTML elements and tags
- Headings, paragraphs, and text formatting
- Links and navigation
- Images and multimedia
- Lists and tables
- Forms and input elements
- Attributes and element properties
- Structuring web page content

*The topics above represent common HTML learning areas; the exact coverage depends on the examples in the collection.*

## Getting Started

No special tools or dependencies are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/HTML__Learnings.git
   ```

2. Navigate to the relevant HTML files.
3. Open an `.html` file in a web browser to view the rendered page.
4. Open the source files in a code editor to explore or modify the examples.
